# Moldova Places Parser

Парсер заведений Молдовы без собственного сайта для поиска потенциальных клиентов веб-разработки.

## Возможности

- 📍 **Источник данных**: OpenStreetMap через Overpass API (бесплатно, без API ключей)
- 🗺️ **Охват**: Вся Молдова кроме Приднестровья (исключено по границам и названиям городов)
- 🏪 **Категории**: Кафе, рестораны, бары, пекарни, кондитерские, салоны красоты, барбершопы, автосервисы
- 🔍 **Классификация сайтов**:
  - Группа A — поле сайта пустое
  - Группа B — только соцсети/агрегаторы/бесплатные конструкторы
  - Группа C — свой домен (отбрасывается)
- ⭐ **Приоритизация**: Оценка по телефону, часам работы, соцсетям, размеру города, категории
- 📊 **Экспорт**: Excel и CSV с удобными колонками для ручной проверки
- 🖥️ **Десктопное приложение**: PyWebView + React интерфейс

## Установка

### Требования
- Python 3.10+
- Node.js 18+ (для сборки UI)
- Git

### Быстрый старт

```bash
# Клонирование
git clone https://github.com/yourusername/moldova-places-parser.git
cd moldova-places-parser

# Установка Python зависимостей
pip install -r requirements.txt

# Установка UI зависимостей и сборка
cd ui
npm install
npm run build
cd ..

# Запуск в режиме разработки (UI на Vite, Python API отдельно)
# Терминал 1:
python -m src.api

# Терминал 2:
cd ui && npm run dev

# Терминал 3:
python src/main.py
```

### Сборка исполняемого файла

```bash
python build.py
```

Исполняемый файл появится в `dist/MoldovaPlacesParser.exe`

## Использование

### Через интерфейс (рекомендуется)
1. Запустите приложение
2. Перейдите на вкладку **Пайплайн**
3. Нажмите **Запустить пайплайн**
4. Дождитесь завершения (несколько минут)
5. Перейдите на вкладку **Заведения** для просмотра, фильтрации и экспорта

### Через командную строку
```bash
# Полный пайплайн
python -m src.parser.main --step 0

# Отдельные шаги
python -m src.parser.main --step 1  # Только выгрузка
python -m src.parser.main --step 2  # Только классификация
python -m src.parser.main --step 3  # Только скоринг
python -m src.parser.main --step 4  # Только экспорт

# Возобновление с промежуточного файла
python -m src.parser.main --step 3 --resume data/processed/step2_groups_ab.parquet
```

## Конфигурация

Все настройки в папке `config/` (YAML файлы):

- `categories.yaml` — OSM теги для каждой категории, поля для извлечения
- `excluded_regions.yaml` — границы Приднестровья, список исключаемых городов, районы для выгрузки
- `social_domains.yaml` — домены соцсетей/агрегаторов/бесплатных конструкторов (группа B)
- `scoring_weights.yaml` — веса для расчёта приоритета, пороги, тиры городов

## Выходные данные

### Excel/CSV колонки
- Название, Категория, Город, Адрес, Телефон, Часы работы
- Мобильный, Email, Контактное лицо, Оператор, Бренд
- Соцсеть, Website, Contact Website, Facebook, Instagram, Telegram, WhatsApp
- Группа (A/B), Приоритет (баллы), Уровень приоритета
- Ссылка на Google Maps
- Пустые колонки для ручной проверки: Проверено, Примечания, Контактное лицо (доп.), Телефон (доп.), Email (доп.), Статус

## Лимиты Overpass API

- 1 запрос в секунду (автоматически соблюдается)
- Таймаут 180 секунд на запрос
- Выгрузка разбита по ~35 регионам для избежания лимитов
- Кэширование ответов в `data/raw/` — повторные запуски быстрее

## Исключение Приднестровья

Два уровня фильтрации:
1. **По координатам** — bbox левого берега Днестра (28.8-30.2°E, 46.5-47.8°N)
2. **По названиям в адресе** — Тирасполь, Бендеры/Тигина, Рыбница, Слободзея, Григориополь, Каменка, левобережные сёла Дубоссарского района
